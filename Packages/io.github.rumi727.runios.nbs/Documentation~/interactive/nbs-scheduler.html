NBS 예약 시뮬레이터

FMOD 믹서의 블록, NBSClockAnchor, NBSPlaybackWorker의 lookahead 예약, time/outputTime 보간을 실제 코드와 같은 식으로 축소해 움직입니다. 소리는 나지 않습니다. 정방향(tempo > 0), 노트 배치는 attackAtNote + pitch > 0만 다룹니다.

① DSP 클록 위의 블록과 예약 (가로 = 샘플)

이미 출력됨 링 버퍼 (믹스 끝, 출력 대기) 지금 믹스 중 예약 끝난 범위 (next mix clock → cursorClock) 예약된 Voice (SetDelay startClock) 앵커

② 벽시계에 따른 타임라인 위치 (최근 구간)

time (믹서 기준, 보간) outputTime (보간) 실제로 스피커에서 나는 위치 명령 · 아래 점: 믹스 스탬프 / 위 눈금: 워커 순회

③ 상태

"시작 오차"는 Voice가 실제로 시작하는 클록과 앵커 직선이 말하는 이상적인 클록의 차이입니다. 늦은 시작이 아니면 항상 0 샘플입니다. 워커 흔들림을 키우거나 lookahead를 0으로 줄여 보세요.

④ 이벤트 로그 (최근 순)

    읽는 법

    재생을 누르면 앵커가 다음 믹스 클록(①의 빨간 선 = master + 1블록)에 찍히고, 그 순간까지 time은 멈춰 있습니다(②의 평평한 구간). 워커는 workerInterval마다 깨어나 (cursor, next mix clock + lookahead·tempo] 안의 노트를 정확한 클록에 예약합니다(①의 주황 점이 회색 눈금에 정확히 겹침). tempo를 바꾸면 앵커가 다시 찍히고 대기 중인 Voice가 비례 이동합니다. 일시 정지는 대기 중인 Voice를 취소하고, 재개하면 앵커부터 다시 예약합니다. 반복을 켜고 6초 근처로 seek하면 쿼리가 반복 구간을 펼쳐 2초 쪽 노트를 미리 예약하는 것을 볼 수 있습니다.

    대응 코드: NBSClockAnchor.TryGetNextMixClock, NoteBlockSource.Clock(SyncTimeToStampUnsafe, GetMixTimestamp), NBSVoiceScheduler.Tick/ScheduleUnsafe/CreateVoiceUnsafe/OnRateChanged/Pause/UnPause/OnLoopChanged, NBSTimeline.Query. 문서: NBS 작동 원리.
